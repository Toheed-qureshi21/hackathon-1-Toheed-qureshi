# RedeemTrip icon assets

Individual SVG icons in a consistent 24×24 stroke style, designed for the RedeemTrip dark-first interface.

- SVG files are standalone vector assets.
- Default strokes use muted RedeemTrip secondary text (#9AA7BD); selected emphasis icons use lime (#C7F36B).
- To use in HTML: `<img src="assets/icons/search.svg" alt="Search">`
- In React/Next.js, these can be imported as SVG assets or converted into components according to the project's SVG setup.

Icons included: search, map-pin, calendar, users, seat, credit-card, award, plane, sparkles, arrow-up-right, arrow-right, chevron-down, send, plus, message-circle, bookmark, settings, check, close, menu, clock, wallet, globe, info, google-g.
